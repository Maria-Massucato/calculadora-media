# Calculadora de Média Escolar

Projeto prático desenvolvido para o minicurso de **Git, GitHub e Git Graph**, com o objetivo de demonstrar o versionamento de código e o uso de mensagens padronizadas seguindo a especificação **Conventional Commits**.

## Funcionalidades

- Cálculo da média aritmética simples entre duas notas bimestrais.
- Validação de campos vazios e de intervalo permitido (`0` a `10`).
- Exibição automática da situação do estudante (`Aprovado` para média $\ge 6{,}0$ ou `Em recuperação` para média $< 6{,}0$).

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
